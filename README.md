# Photo Engine

ブラウザだけで動く、シンプルなローカル画像編集アプリです。画像が外部へアップロードされることはありません。

## 機能

- 画像選択とドラッグ＆ドロップ
- 明るさ、コントラスト、彩度、色温度の調整
- 回転、左右反転、上下反転
- 編集前との比較
- PNG、JPEG、WebP形式での書き出し
- モバイル表示対応

## 使い方

`index.html` をブラウザで開き、画像を選択してください。ローカルHTTPサーバーから開く場合は、任意の静的ファイルサーバーでこのディレクトリを配信します。

## 開発

実行時には `script.js` を使用します。編集元は `script.ts` です。

## 現在の範囲

JPEG、PNG、WebPなど、ブラウザが標準で読み込める画像形式を対象としています。RAW現像には対応していません。
